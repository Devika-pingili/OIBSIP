# Personal Portfolio Website

A simple and responsive personal portfolio website built using **HTML5** and **CSS3** as part of the **Oasis Infobyte Web Development & Designing Internship** (Level 1 - Task 2).

## Description

This portfolio showcases my skills, projects, and contact information as a Computer Science Engineering student and aspiring web developer. The website is built from scratch without any CSS frameworks or JavaScript, focusing on clean layout, readability, and responsive design.

## Features

- Sticky navigation bar with smooth scrolling
- Hero/Profile section with introduction and call-to-action buttons
- About Me section with personal background
- Skills section with language and tool cards
- Projects section with responsive project cards
- Contact section with email and social links
- Footer with quick links and social icons
- Fully responsive layout (desktop, laptop, tablet, mobile)
- CSS hover effects on buttons, cards, and navigation links
- Semantic HTML for better accessibility

## Folder Structure

```
Portfolio/
│── index.html          # Main HTML file
│── style.css           # All CSS styles
│── images/
│   └── profile.svg     # Profile image placeholder (replace with your photo)
│── README.md           # Project documentation
```

## Technologies Used

- HTML5
- CSS3 (Flexbox, CSS Grid, CSS Variables, Media Queries)
- Google Fonts (Poppins & Open Sans)

## How to Run

1. Download or clone this project folder.
2. Open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, etc.).
3. No installation or build step is required.

**Optional:** Replace `images/profile.svg` with your own profile photo (keep the same filename or update the path in `index.html`).

Also update placeholder links in the Contact section and project cards with your real email, GitHub, and LinkedIn URLs.
