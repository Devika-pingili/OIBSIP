# Nomad Brew — Landing Page

**Where Every Cup Begins a New Journey.**

A responsive, professional landing page for a fictional travel-inspired café, built as part of the **Oasis Infobyte Web Development & Designing Internship — Level 1, Task 1**.

---

## Description

Nomad Brew is a modern coffee shop landing page that blends the warmth of a café with the excitement of travel. The design is clean, elegant, and fully responsive — built using **only HTML5 and CSS3** with no JavaScript or CSS frameworks.

This project demonstrates foundational web development skills including semantic HTML, CSS Flexbox & Grid, responsive design, CSS variables, and accessible markup.

---

## Features

- **Sticky navigation bar** with logo, 5 nav links, and a Reservation button
- **Hero section** with headline, subheadline, CTA button, and illustration
- **Why Choose Us** — 3 feature cards with icons and hover effects
- **About Us** — text content, bullet points, and image placeholder
- **Featured Menu** — 6 coffee items displayed in a CSS Grid layout
- **Gallery** — 3 image placeholders showcasing café moments
- **Customer Testimonials** — 3 review cards with avatars and star ratings
- **Call to Action** — full-width banner with heading and button
- **Footer** — 4 columns (About, Quick Links, Contact, Social Media)
- **Responsive design** — breakpoints at 1200px, 992px, 768px, and 576px
- **Smooth hover animations** — button scale, card lift, nav underline effects
- **Accessibility** — semantic HTML, alt attributes, proper heading hierarchy

## How to Run

No installation or build tools required. Simply open the project in any modern web browser.

### Option 1: Direct open
1. Navigate to the `LandingPage` folder
2. Double-click `index.html` to open it in your default browser

### Option 2: Live Server (VS Code)
1. Install the **Live Server** extension in VS Code
2. Right-click `index.html` and select **Open with Live Server**

### Option 3: Command line
```bash
# Navigate to the project folder
cd LandingPage

# Open in default browser (Windows)
start index.html

# Open in default browser (macOS)
open index.html

# Open in default browser (Linux)
xdg-open index.html
```

> **Note:** An internet connection is required on first load to fetch Google Fonts.
