# ☕ Nomad Brew – Travel Café Landing Page

## 📌 Project Overview

Nomad Brew is a responsive landing page created for a fictional travel café as part of **Level 1 – Task 1** of the **Oasis Infobyte Web Development & Designing Internship**.

The website combines the warmth of a coffee shop with the excitement of travel, offering users a clean and engaging browsing experience while demonstrating fundamental web development skills.

---

## ✨ Features

- Sticky Navigation Bar
- Hero Section with Call-to-Action Button
- About Section
- Features Section
- Testimonials Section
- Footer with Contact & Social Links
- Responsive Design for Desktop, Tablet, and Mobile
- Consistent Color Palette and Typography

---
